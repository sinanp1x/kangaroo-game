# kangaroo-game

A p5.js kangaroo jumping game. The kangaroo (3 animation frames) jumps over stones and shrubs (3 frames each) using the spacebar. Collision plays a 'collided' sound and shows a Game Over screen with restart. Includes background and jump/restart sound effects.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
